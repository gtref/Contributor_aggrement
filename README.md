# Contributor Agreement

## Overview
Contributor Agreement is a reusable, versioned contributor agreement designed for open-source projects. This repository contains the official website skeleton and document versions.

## How to Use the Site
1. Browse through the available versions in the [Versions](docs/versions.md) section.
2. Read instructions on how to adopt the agreement in [Adoption](docs/adoption.md).
3. Follow the [Blog](docs/blog/placeholder.md) for updates and announcements.

## Publishing with GitHub Pages
To publish this site using GitHub Pages:
1. Go to your repository settings on GitHub.
2. Navigate to the **Pages** section under **Code and automation**.
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Select your branch (e.g., `main`) and set the folder to `/docs`.
5. Click **Save**. GitHub Pages will automatically build and publish your site using Jekyll.
